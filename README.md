# DevOps Capstone Project - Customer Accounts Microservice

[![CI Build](https://github.com/Avijit-devops/devops-capstone-project/actions/workflows/ci-build.yaml/badge.svg)](https://github.com/Avijit-devops/devops-capstone-project/actions)

This repository contains the complete Customer Accounts microservice developed as part of the DevOps Capstone Project. It implements RESTful APIs, automated testing, security headers, containerization, and automated CI/CD deployment pipelines.

## Microservice Features
- **REST APIs**: Full CRUD operations for customer accounts.
- **Talisman Security**: Hardened HTTP response headers and Content Security Policies.
- **CORS Policies**: Cross-Origin Resource Sharing enabled for safe API access.
- **Continuous Integration**: GitHub Actions automated linting and test coverage.
- **Containerization**: Dockerfile configured for minimal footprint.
- **Continuous Delivery**: Tekton Pipelines configured for Kubernetes deployment.
